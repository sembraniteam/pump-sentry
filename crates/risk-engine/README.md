# risk-engine — LLM TP/SL with deterministic fallback

Model decides within 300ms (floor 50ms, cap 2s); anything unusable falls back to the heuristic. `evaluate` never fails on model trouble. Undecodable or invalid model output holds PASS (only an explicit valid BUY buys); transport/timeout falls back (entries must not halt when the model is down), and transport errors are logged with endpoint credentials stripped.

- Shapes over a BUY profile: `adaptive` verbatim; `scalp` clamps TP into +25…+35% (sub-band honored, never widened); `runner` forces moonbag + trailing (a trail is forced onto any trailless moonbag).
- Heuristic: PASS on `dev < 0.40`, `rugcheck > 350`, or velocity < 5; momentum tiers map to fixed TP/SL/timeout. High-velocity flow on wash-suspect forensics (bundled creation slot or monopoly-scale cluster) drops to the moderate band, never high-momentum TP.
- Exit regimes (`ExitRegime`) are a closed set (`momentum` / `conservative` / `liquidity_sensitive`): the model may pick, `resolve_regime` snaps the numbers deterministically to the regime's tested profile — free-form TP/SL never reach the book, PASS and invalid pass through, and the heuristic's band profiles already equal two of the regime consts (snap idempotent).
- Contextual tape: confirm metrics carry microstructure (`MicroSignals`), tape volume, top-10 holder concentration, and the measured `entry_flip_loss_pct` — what one ticket costs to open AND immediately sell back at the confirm book (entry impact + exit impact + venue fees; a static-market preview composed from the same fill math the paper book settles with, slightly conservative: the sell leg quotes the pre-buy curve, so marginal entries refuse a touch early). The prompt treats it as the measured replacement of the static 2–4% spread prior: SL never tighter than the measured cost, and a loss that dominates the TP target temps toward PASS / `liquidity_sensitive`. Prompt rules only tighten (PASS/temper on wash, concentration, insider distribution, fading velocity, cost-floor breaches) — the model is a second screener, never a gate override in either direction.
- Confidence telemetry per model: latency p50/p95/p99 over a bounded 256-sample window (timeouts record the budget they cost; transport failures record actual elapsed) plus fallback BUY vs PASS split — so a volume-protecting fallback cannot hide behind the fallback rate alone.
- Fixed decoding (`temperature 0.1`, `max_tokens 1024`): deterministic numeric output; retuning voids the compliance assumptions above. The cap only truncates, never targets: non-reasoning models stop at EOS, while reasoning models spend reasoning tokens from the same output budget — a 128 cap truncated mid-reasoning into empty content, which JSON-mode endpoints reject.
- Optional extra headers (`.header()` / `.headers()`, e.g. `x-opencode-session` for OpenCode Go routing): sent on every request; `authorization`/`user-agent`/framing headers are refused at build; values never logged.
